# Linguagem-C

### Maximização de Lucro em C

Programa desenvolvido em linguagem C para resolver um problema simples de **Programação Linear**. O código testa diferentes quantidades dos produtos A e B, verifica as restrições de matéria-prima, mão de obra e máquina, e identifica a combinação que proporciona o maior lucro.

O projeto demonstra na prática a aplicação de **otimização, estruturas de repetição, condicionais e cálculo de funções objetivo** em C.
